Documentation Cryptographique

Fondations théoriques, preuves de sécurité de Bellare-Canetti-Krawczyk et vecteurs de test officiels HMAC-SHA256.

functions Construction Formelle HMAC
B = 64 octets
DÉFINITION MATHÉMATIQUE lock
HMAC(K, M) = H( (K' ⊕ opad) || H( (K' ⊕ ipad) || M ) )
K'

Clé normalisée à B octets (64 octets pour SHA-256 avec padding 0x00).

ipad

Constante interne 0x36 répétée 64 fois (Inner Pad, masquage préliminaire).

opad

Constante externe 0x5c répétée 64 fois (Outer Pad, décorrélation externe).

||

Opérateur de concaténation binaire ordonnée des flux d'octets cryptographiques.

Théorème Fondateur PROUVÉ INVIOLABLE (PRF)

Théorème de Bellare-Canetti-Krawczyk (1996)

Si la fonction de compression sous-jacente de la fonction de hachage est un PRF (Pseudo-Random Function), alors la construction HMAC forme un PRF universellement prouvé, même si l'algorithme complet présente une faiblesse aux collisions simples.

MAC Naïf : H(K || M) Vulnérable

Exposé à l'attaque par Extension de Longueur (Length Extension). Un attaquant peut forger un suffixe valide sans connaître la clé secrète K.

HMAC : Double Étage Décorrélé Immunisé

L'enveloppe externe H(opad || ...) scelle hermétiquement l'état interne de Merkle-Damgård, rendant l'injection d'octets impossible.
