Démystifier l'intégrité cryptographique et la résilience face à la falsification réseau (RFC 2104 / FIPS 198-1).

Un simple condensat SHA-256(Message) sans clé symétrique permet à l'espion de recalculer le hash sans se faire repérer. Un MAC naïf type H(K || M) est vulnérable à l'extension de longueur. Seul HMAC-SHA256 (nested hashing) verrouille l'intégrité de bout en bout.
